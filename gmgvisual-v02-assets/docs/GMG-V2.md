# GMG Visual v2 — Project Brief

You will be working on an existing website for **GMG Visual**.

This is **NOT** a complete redesign.

The goal is to evolve the current website while preserving as much of the existing codebase, layout, components and animations as possible.

Do not rebuild components that already work well.

Do not reinterpret the project or introduce your own design ideas.

Treat the current website as the foundation.

---

## Project Goal

Transform GMG Visual from a videographer portfolio into the website of a modern creative studio.

The website should communicate confidence, simplicity and professionalism.

It should present GMG Visual as a creative partner helping businesses, brands and creators build a strong digital presence.

---

## Design Principles

* Minimal
* Clean
* Editorial
* Timeless
* Spacious
* Fast
* Mobile-first

Avoid unnecessary visual effects, decorative elements or complex interactions.

Every section must have a clear purpose.

## General Rules

* Reuse existing code whenever possible.
* Preserve existing animations unless requested otherwise.
* Keep the code clean and maintainable.
* Never redesign sections that are not part of the current task.
* If something is unclear, ask before making assumptions.
* Focus on implementation rather than reinterpretation.
