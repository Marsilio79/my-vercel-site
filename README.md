# GMG Visual Website

Official website for GMG Visual.

Built with:

- Next.js 15
- TypeScript
- Tailwind CSS
- Netlify

## Live Website

https://gmgvisual.com

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

The website is automatically deployed through Netlify whenever changes are pushed to the `main` branch.
